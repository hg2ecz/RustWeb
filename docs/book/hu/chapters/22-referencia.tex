\section{Napi fejlesztési ellenőrzőlista}

\begin{enumerate}
  \item Typed route/input és zárt választásnál enum.
  \item User input nem kerül raw SQL-be vagy raw HTML-be.
  \item Mutáció transactionben.
  \item Sikeres POST után PRG redirect.
  \item User/session dependent oldal nem public cache.
  \item Secret csak \code{*_file} formában.
  \item Release előtt \code{./verify.sh}, config check és migration verify.
  \item Production után live/ready, log, metric és audit review.
\end{enumerate}
