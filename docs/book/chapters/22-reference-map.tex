\section{Daily development checklist}

\begin{enumerate}
  \item Use typed route/input contracts, and an enum for closed choices.
  \item Never place user input into raw SQL or raw HTML.
  \item Perform mutations inside a transaction when the business operation must be atomic.
  \item After a successful browser POST, use Post/Redirect/Get.
  \item Do not public-cache pages that depend on user/session state.
  \item Supply secrets only through \code{*_file} boundaries.
  \item Before release, run application checks, configuration preflight, and migration verification; when releasing the RWLang platform itself, also run \code{./verify.sh}.
  \item After deployment, verify live/ready, logs, metrics, audit, and an application smoke path.
\end{enumerate}
